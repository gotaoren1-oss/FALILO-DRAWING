# FALILO באתר משלך: GitHub Pages + Google Drive

ההתקנה נעשית פעם אחת וכולה בחינם. בסופה יש לך:
- כתובת קבועה ל-FALILO;
- אייקון באייפד שנפתח במסך מלא ועובד גם בלי אינטרנט;
- שמירה ישירה ל-Google Drive שלך;
- כניסה שפתוחה רק לחשבון Google שלך.

## שלב 1: העלאה ל-GitHub (בערך 5 דקות)
1. נכנסים ל-github.com ופותחים חשבון אם אין לך עדיין. מומלץ להפעיל אימות דו-שלבי (Settings → Password and authentication).
2. בפינה העליונה לוחצים **+ ← New repository**. נותנים שם, למשל `falilo`, ומשאירים **Public**. בקוד אין שום סוד, וזה מוסבר בחלק על האבטחה.
3. בדף שנפתח לוחצים **uploading an existing file** וגוררים את **כל הקבצים מהתיקייה הזו**. לוחצים **Commit changes**.
4. נכנסים ל-**Settings ← Pages**. תחת Branch בוחרים **main** ואת התיקייה **/ (root)**, ולוחצים **Save**.
5. אחרי דקה-שתיים מופיעה כתובת כמו `https://השם-שלך.github.io/falilo/`. זו הכתובת של FALILO.

## שלב 2: מזהה חיבור מ-Google (בערך 10 דקות)
1. נכנסים ל-console.cloud.google.com ויוצרים פרויקט חדש, למשל FALILO.
2. **APIs & Services ← Library**: מחפשים **Google Drive API** ולוחצים **Enable**.
3. **APIs & Services ← OAuth consent screen**:
   - סוג **External**;
   - שם האפליקציה FALILO והמייל שלך;
   - ב-**Test users** מוסיפים **רק את המייל שלך**. כך Google עצמו לא ייתן לאף חשבון אחר להתחבר.
4. **APIs & Services ← Credentials ← Create credentials ← OAuth client ID**:
   - סוג **Web application**;
   - ב-**Authorized JavaScript origins** מוסיפים את הכתובת משלב 1 בלי הנתיב, למשל `https://השם-שלך.github.io`;
   - לוחצים **Create** ומעתיקים את ה-**Client ID**.

ה-Client ID הוא לא סוד, והוא תמיד גלוי באתר. לא צריך API Key ולא Client Secret. **לא שולחים לאף אחד סיסמאות או Client Secret, גם לא לי.**

## שלב 3: ממלאים את config.js
ב-GitHub פותחים את הקובץ `config.js`, לוחצים על העיפרון (Edit) וממלאים:
```
window.FALILO_OWNER = "המייל-שלך@gmail.com";
window.FALILO_GCID  = "1234-abcd.apps.googleusercontent.com";
```
בסוף לוחצים **Commit changes**.

## שלב 4: באייפד
1. פותחים את הכתובת ב-Safari.
2. לוחצים על כפתור השיתוף ואז **הוספה למסך הבית**.
3. מתחברים עם Google פעם אחת.

מעכשיו כל פרויקט חדש שואל איפה לשמור אותו, ונשמר גם ב-Drive בתיקייה `FALILO/שם הפרויקט`.

## אבטחה: למה אף אחד לא יכול לפגוע
- **הקוד:** רק מי שמחובר לחשבון GitHub שלך יכול לשנות את האתר. מבקר באתר רק רואה עותק ולא יכול לשנות כלום. לכן חשוב להפעיל אימות דו-שלבי ב-GitHub.
- **הנתונים שלך לא נמצאים באתר בכלל:**
  - הפרויקטים נשמרים במכשיר שלך וב-Drive שלך.
  - מי שנכנס לכתובת ממכשיר אחר מקבל תוכנה ריקה, בלי שום מידע שלך.
- **מסך כניסה לבעלים:** כשממלאים את `FALILO_OWNER`, התוכנה נפתחת רק אחרי התחברות עם המייל הזה. חשבון אחר נחסם.
- **Google:** יש שני מנגנונים שמגבילים את הגישה:
  - מצב Test users מתיר התחברות רק לחשבון שלך.
  - ההרשאה היא `drive.file`. FALILO רואה ב-Drive רק קבצים שהוא עצמו יצר, ולא את שאר הקבצים שלך. הוא גם לא מקבל שום גישה למייל.
- **חסימת תוספות זרות:** האתר מוגדר לא להריץ שום קוד מבחוץ. הוא מדבר רק עם Google.
